# Parish's Pistol Pointers

A deliberately dated parody website for a fictional gun safety course in Surprise, Arizona.

## Website

Plain HTML, CSS, and JavaScript with the supplied MP4 video and poster image. Open `index.html` locally, or serve this directory with any static web server.

GitHub Pages publishes the root of the `main` branch. Push changes to `main` to update the site.

This is a fictional mock course, not real training or certification.
